# Un pequeño universo para ti

Regalo digital interactivo. Sin backend, sin dependencias — solo `index.html`, `style.css` y `script.js`.

## Cómo verlo

Abre `index.html` directamente en el navegador con doble clic. Funciona sin servidor.

## Cómo agregar la música

1. Consigue un archivo de audio propio (sin derechos de autor de terceros).
2. Renómbralo a `musica.mp3`.
3. Colócalo en esta misma carpeta, junto a `index.html`.
4. El botón ♫ (arriba a la derecha) la activa o la silencia. Si el archivo no existe, la página funciona igual — solo no habrá música.

## Cómo publicarlo gratis

**GitHub Pages**
1. Crea un repositorio nuevo y sube estos archivos (incluyendo `musica.mp3` si ya lo agregaste).
2. Ve a *Settings → Pages*, selecciona la rama `main` y la carpeta raíz.
3. GitHub te da un enlace público tipo `https://tuusuario.github.io/turepo/`.

**Netlify**
1. Entra a [netlify.com](https://www.netlify.com) e inicia sesión.
2. Arrastra la carpeta completa del proyecto al panel de "Deploys" (drag & drop).
3. Netlify genera un enlace público al instante.

**Vercel**
1. Entra a [vercel.com](https://vercel.com) e inicia sesión.
2. "Add New Project" → sube la carpeta o conéctala a un repo de GitHub.
3. Deploy y listo, obtienes el enlace.

Cualquiera de las tres opciones te da un link que puedes enviar directamente.
